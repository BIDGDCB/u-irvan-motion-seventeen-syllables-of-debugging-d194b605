# Seventeen Syllables of Debugging

Entry for the make.fun competition `u-irvan-motion-seventeen-syllables-of-debugging-d194b605`.

`main.ts` writes a haiku about debugging in the 5-7-5 syllable shape to `/output/entry.txt`. The text is validated
before it is written: 1 to 200 characters, not only white space.

The entry text:

> a midnight breakpoint / the log swears nothing is wrong / the bug grins back
